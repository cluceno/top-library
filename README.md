# top-library


For this project, I will be making a library table that will have columns for an author, title, number of pages, book ID, and whether it's been read or not. 

There will be a buttons to interacto with: 
    - add a book
    - Changed read status

The book info will be stored in an array of objects. The array will be looped through and displayed into a table that will be interactive.

Key learning points: 

1. When you make changes to the data, in this case myLibary, you must rerender each time to avoid duplicates in the DOM. Keep track of the data and how it is being presented. 

2. When you rerender, make sure to delete what was already there so that it  doesn't keep stacking on old data. 

3. when the input type is text, selecting it points to the container. .value is what is in the box at the time.

Overall impression: This was a great exercisie to practice HTML, CSS, and JS. It was a multifaceted project that forced me to practice and review certain topics. I had to remember how to make a table and form and then format it. I also got practice with making an interactive DOM.
